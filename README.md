# NotaFlow Android - Cloud APK build

This repository contains NotaFlow Deluxe and a GitHub Actions workflow that builds a debug APK.

## Build
1. Create a GitHub repository and upload the contents of this ZIP (not the ZIP itself).
2. Open the **Actions** tab.
3. Select **Build NotaFlow APK**.
4. Press **Run workflow**.
5. After it finishes, open the run and download the **NotaFlow-APK** artifact.

The APK is a debug build intended for personal installation/testing. It is not a Play Store release build.
